# メルマガ配信ツール セットアップ手順（20分）

Googleスプレッドシートを配信管理台帳にして、Gmailから送るツールです。
外部サービスの契約は要りません。Googleアカウント（rei.stella1127@gmail.com）での作業になります。

**先に知っておくこと**

- 送信はGmailの上限に従います。**無料のGmailは1日100通、Google Workspaceは1日1,500通**です
- お問い合わせフォームの自動返信（`gas/contact-form.gs`）と**同じアカウントなら上限を分け合います**。
  設定シートの「予備に残す通数」が、その自動返信のために取っておく枠です
- 1日で送りきれない分は、翌日に自動で続きます

---

## 1. スプレッドシートを作る

1. https://sheets.new を開く（rei.stella1127@gmail.com でログインした状態で）
2. ファイル名を「**Stellize メルマガ配信**」に変更

## 2. スクリプトを貼り付ける

1. メニューの「拡張機能」→「Apps Script」を開く
2. 最初からある `function myFunction() {...}` を全部消す
3. `gas/newsletter/` の中のファイルを、次のとおり追加します

**`.gs` ファイル**（左の「ファイル」の＋→「スクリプト」）。名前は拡張子なしで入れます。

| 作るファイル名 | 貼り付ける中身 |
|---|---|
| `Config`    | `Config.gs` |
| `Templates` | `Templates.gs` |
| `Render`    | `Render.gs` |
| `Sheets`    | `Sheets.gs` |
| `Compose`   | `Compose.gs` |
| `Send`      | `Send.gs` |
| `Web`       | `Web.gs` |
| `Menu`      | `Menu.gs` |

（最初からある `コード.gs` は、上のどれか1つを貼って名前を変えるか、消してかまいません）

**`.html` ファイル**（＋→「HTML」）。こちらも名前は拡張子なしです。

| 作るファイル名 | 貼り付ける中身 |
|---|---|
| `Sidebar` | `Sidebar.html` |
| `Import`  | `Import.html` |

4. 💾（保存）を押す。プロジェクト名は「Stellizeメルマガ」などでOK

> `Templates.gs` と `Render.gs` は**自動生成ファイル**です。中身を直したいときは
> `mail/` 側を直して `node mail/build.mjs` を実行し、あらためて貼り直してください。

## 3. シートを整える

1. スプレッドシートのタブに戻って、**ページを再読み込み**する
2. 上のメニューに「**📧 メルマガ**」が出る（出ないときは数秒待ってもう一度再読み込み）
3. 「📧 メルマガ」→「**初期セットアップ（シートを整える）**」
4. 初回だけ承認を求められます
   → 自分のアカウントを選択 →「このアプリは Google で確認されていません」と出たら
   「詳細」→「（プロジェクト名）に移動」→「許可」
   （自作スクリプトなので出る警告です）
5. 「完了しました」と出れば、6枚のシートができています

## 4. デプロイする（配信停止リンクを作るために必須）

1. Apps Script の画面に戻り、右上の「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「**ウェブアプリ**」を選択
3. 設定を以下にする
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員** ← ここ重要
     （メールの受信者はGoogleにログインしていないため）
4. 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/～/exec`）をコピー

## 5. 設定シートを埋める

スプレッドシートの「**設定**」シートを開き、値の列を埋めます。

| 項目 | 入れるもの |
|---|---|
| **WebアプリURL** | 手順4でコピーしたURL。**これが無いと送信できません** |
| 差出人名 / 返信先 | 受信者に見える名前と、返信の宛先 |
| 会社名 / 住所 | フッターに出ます。**特定電子メール法で表示が必須**です |
| サイトURL / ロゴURL / お問い合わせURL | 独自ドメインを取ったら差し替えてください |
| 1日の送信上限 | 無料Gmailなら `80`、Workspaceなら `400` くらいから始めるのが安全です |
| 予備に残す通数 | お問い合わせ自動返信のために残す枠（`30` 程度） |

「説明」の列に、それぞれ何のための値かが書いてあります。

## 6. 送り先を入れる

「📧 メルマガ」→「**購読者をまとめて取り込む**」に、CSVやスプレッドシートからコピーして貼り付けます。
1行目は見出し行で、`メールアドレス` 列が必須です。

**「許諾の根拠」は必ず埋めてください。** 例：`公式サイトの問い合わせページに公開されている法人の連絡先（2026-09-07確認）`。
根拠を残しておくことが、法令上も、あとで説明できるようにするためにも要ります（詳しくは `mail/README.md` の「法令」）。

## 7. 原稿を書く

1. `mail/builder/index.html` をブラウザで開く
2. 書けたら「**スプレッドシート用にコピー**」
3. 「**原稿**」シートで、「📧 メルマガ」→「新しい号の行を作る」を押す
4. できた行の「テンプレート」のセルを選んで貼り付ける（テンプレート〜本文が一度に入ります）

## 8. 送る

1. 「📧 メルマガ」→「**配信パネルを開く**」
2. 号を選ぶ → 「プレビュー」で見た目を確認
3. 「**テスト送信する**」→ 届いたメールを**スマホでも**開き、リンクと配信停止を全部押す
4. 問題なければ「**この号を送信する**」。件数を確認するダイアログが出ます

送信中はパネルに進捗が出ます。1日の枠を使い切ったら止まり、翌日に自動で続きます。
途中でやめたいときは「止める」。すでに送った分は取り消せません。

---

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| メニュー「📧 メルマガ」が出ない | スプレッドシートを再読み込み。それでも出ないなら `Menu` ファイルの貼り付け漏れ |
| 「WebアプリURLが正しくありません」 | 設定シートのURLの末尾が `/exec` か。`/dev` ではだめです |
| 「宛先が0件です」 | 購読者シートの「状態」が `購読中` か、「セグメント」が原稿と一致しているか |
| 配信停止リンクを押すとエラー | デプロイの「アクセスできるユーザー」が **全員** になっているか |
| 途中で止まったまま進まない | パネルの「続きを送る」。当日の枠を使い切っている場合は翌日まで待ちます |
| 送信済みなのに届かない | 迷惑メールフォルダ。件名に「!」「無料」を並べていないか。テキスト版は自動で付いています |
| コードを直したのに反映されない | デプロイし直しが必要です（「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ） |

## 動作を手元で確かめる

GASに貼る前に、Node上で通し確認ができます（本物のスプレッドシートもGmailも使いません）。

```bash
node gas/newsletter/test/smoke.mjs
```

シートの初期化・取り込み・チェック・組み立て・送信・配信停止・分割送信と再開までを一通り実行します。
`Send.gs` などを直したら、貼る前にこれを走らせてください。
