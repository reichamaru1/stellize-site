# 俺の事業を管理せよ

Stellizeの事業を1画面にまとめるデスクトップアプリ。
**外部ライブラリへの依存はありません**（Node 22.5+ 同梱の `node:sqlite` と標準モジュールのみ）。

```
お金
  ダッシュボード   その月の収支・契約・フォロー待ち・直近の動き
  お金の流れ       入出金の推移とカテゴリ別、明細検索
  月次損益         年ごとのP/L（売上・売上原価・販管費・利益）2023〜2026
  経費・勘定       勘定科目別・経費カテゴリ別、明細
  計画と実績       月次の目標／実績／目安、事業パラメータ
売る
  顧客・案件       商談パイプライン / 契約一覧 / 人脈台帳 / 名刺 / 協業先
  交流会           会ごとの費用対効果（アポ単価・成約単価）
  事業所リスト     全国の就労支援事業所 32,147件を検索
  メルマガ         今日の枠・ネタ帳・直近の号（配信ツールに接続）
調べる
  KPI              週次の目標と実績、達成率
  料金表           単価・原価・粗利率
  取り込みの検算   シートの集計との突き合わせ、取込ログ、判定ルール
  設定             メルマガ連携、取り込み手順
```

## 起動

`俺の事業を管理せよ.app` をダブルクリック。専用ウィンドウが開きます。
（Chrome / Edge / Brave があればアプリモード、無ければ既定のブラウザ）

ターミナルから動かす場合：

```bash
npm start        # http://localhost:8710
```

## データの取り込み

事業管理シート（Googleスプレッドシート）から取り込みます。

1. スプレッドシートをMarkdownで書き出し、`data/sheet-export.md` に置く
2. `npm run import`

何度実行しても同じ結果になります（`source_key` で上書きするため）。
シートを更新したら、書き出し直して流し直してください。

## 検算

```bash
npm run verify
```

件数が合っていても、列を1つ読み落とせば金額は狂います。そこで3段で確かめています。

1. **連番に欠けが無いか** … 行が落ちていないか
2. **差引残高が最後まで積み上がるか** … 1円でも読み違えたら合わない
3. **シート自身の集計との突き合わせ** … 合わない場合はどちらが正しいかを示す

現在の結果：

- 入出金明細 247件すべてで差引残高が一致（最終 -¥1,159,341）
- 月次損益：総売上 24/24か月、販管費 24/24か月が内訳と一致
- 収支ダッシュボード：**支出が12/12か月、経費明細と完全一致**

一致しない箇所は、いずれも**シート側の内部矛盾**です（アプリの「取り込みの検算」画面にも出ます）。

| 箇所 | 内容 |
|---|---|
| 収支ダッシュボードの収入 | シートは4月以降を見込み額で埋めている（実績ではない） |
| 【収入カテゴリ別】【支出カテゴリ別】 | 明細と噛み合わない。別シートを集計しているか、古い値 |
| 2024-01 の実績合計売上高 | 【トイエバ】¥149,000 がその月だけ合計から外れている |

## データの置き場所

| | 場所 | 誰が正か |
|---|---|---|
| お金・顧客・案件・KPI | `data/ore.db` | **このアプリ** |
| 事業所 32,147件 | `../shuro-db/data/shuro.db` | shuro-db（読み取り専用で開く） |
| メルマガ | GASのWebアプリ | スプレッドシート側 |

`data/` は `.gitignore` 済みです。**入出金・経費・人脈が入るのでコミットしないでください。**

## メルマガ連携

「設定」画面に、スプレッドシートの「📧 メルマガ」→「ネタ帳のURLと連携キーを表示」で出る
WebアプリURLと連携キーを入れます。連携キーは `data/ore.db` にだけ保存され、画面には出しません。

接続すると、メルマガ画面で今日の枠・未使用のメモ・直近の号が見え、
PCからもネタ帳にメモを残せます。**送信はこのアプリからは行いません**（配信パネルで人が押します）。

## 設計メモ

- 金額は円の整数で持つ。小数は使わない（消費税の丸めで必ず事故る）
- 日付は `YYYY-MM-DD` の文字列（SQLiteに日付型は無い）
- 表の見つけ方は「見出し行の列名」。行番号で決め打ちすると、シートに1行挿入されただけで全部ずれる
- ダッシュボードは暦の今月ではなく「記帳がある最後の月」を出す。月初に¥0が並ぶのを避けるため
